EOV Metadata and Data Tools

UNDER DEVELOPMENT: aspects of this tool are still in development. Feedback is welcome and can be provided by adding a GitHub issue or reaching out to e.lawrence@unesco.org

Welcome! This application has two main functions:
  • 1) submit metadata describing EOV monitoring efforts to the GOOS BioEco Portal.
  • 2) provide tools for managing EOV datasets and converting them into Darwin Core, to be submitted to OBIS (work in progress)
Please note the distinction between data producer metadata and dataset metadata. Data producers ARE the entities that collect information about and monitor EOVs, while datasets are produced FROM data producers. For more information about EOV data management, see the EOV Data Management Guidelines, which are associated with the GOOS BioEco EOV Specification Sheets.
