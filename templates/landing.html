Welcome to the EOV Metadata Submission & Data Tool Application

This application has two main functions:

  • 1) facilitate metadata submission to the GOOS BioEco Portal and Ocean Data Information System (ODIS) for EOV data producers,
  • 2) provide tools for managing EOV datasets and converting them into Darwin Core, to be submitted to OBIS (Work in progress)
Please note the distinction between data producer metadata and dataset metadata. Data producers ARE the entities that collect information about and monitor EOVs, while datasets are produced FROM data producers.

You must have a GitHub account to use this tool as submissions are sent to the GitHub repository.

Required Metadata

The following metadata fields are required for submission:

  • Name of data producer
  • URL of landing page
  • Frequency of updates to metadata
  • Contact name, email (e.g. helpdesk, general support)
  • Name(s) of relevant EOV(s)

Additional metadata fields are optional but encouraged, and include:

  • Name and identifier of parent organization
  • Description or abstract
  • License, or other relevant policies
  • Funder information
  • Sampling frequency and approach
  • Keywords
  • Geographic and temporal coverage
  • URLs or related outputs
