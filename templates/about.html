About

These tools are being developed by Elizabeth Lawrence from IOC-OBIS, supported by the EU-funded project BioEcoOcean. AI (ChatGPT-4 and -5) was used to assist with the development and all code generated was reviewed, tested, and edited as necessary before being implemented.

Data management guidelines for EOV metadata and data are outlined here. Aligning with FAIR principles, metadata about data producers ultimately should be visible in ODIS and the GOOS BioEco Portal. BioEco EOV data can be published to OBIS, which requires it to be formatted according to the Darwin Core standard. This tool is designed to facilitate the process of creating metadata and data files that are compliant with these standards.
